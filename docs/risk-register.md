# Risk register — BitCode.Framework

**Tarea:** F0-12 (Fase 0 — Gobierno, arquitectura y línea base) del [Plan Maestro de BitCode](plan-maestro-bitcode-ia.md).
**Fecha:** 2026-09-06
**Estado:** **Pendiente de revisión por responsables.** El criterio de aceptación de F0-12 exige que el registro sea "revisado por responsables"; no hay responsables humanos de arquitectura/seguridad/infraestructura/producto asignados todavía en este repositorio (precondición de Fase 0 aún no cumplida formalmente). Este documento consolida riesgos ya identificados y evidenciados en tareas previas — no inventa riesgos nuevos sin base documental.

**Método:** cada riesgo de este registro proviene de un hallazgo ya registrado en `docs/threat-model.md` (F0-07), un ADR en estado `Proposed` (`docs/adr/`), `docs/politica-dependencias.md` (F0-06), `docs/adr/0012-dbcontext-pooling-no-adoptado.md`, `docs/benchmark-multitenancy.md` (F1-11) o `docs/matriz-soporte.md` (F1-05). No se agregó ningún riesgo sin una fuente citable.

---

## 1. Escala usada

- **Probabilidad:** Alta / Media / Baja — estimación cualitativa basada en si el vector ya está confirmado como explotable (Alta), es plausible dado el estado del código pero requiere una condición adicional (Media), o depende de una decisión externa que todavía no se tomó (Baja, mientras esa decisión no se tome).
- **Impacto:** Alto / Medio / Bajo — Alto si compromete confidencialidad/integridad de datos entre tenants, disponibilidad del servicio o cumplimiento normativo; Medio si degrada calidad, rendimiento o auditabilidad sin comprometer directamente seguridad; Bajo si es una mejora de higiene técnica sin exposición directa.
- **Owner:** rol genérico, no nombre de persona (no hay responsables humanos asignados — ver estado del documento).
